**The Midnight Vault** — a top-down heist game on one bank floor. Tonight the Star Diamond sits in the vault of Bank Swasta Nusantara; at dawn it leaves under guard. Play Hantu, the Ghost: pickpocket the keycard from supervisor Pak Darma, dodge Bima's patrol and Sari's phone breaks, cut the power and cross the dark bank by flashlight, open the vault, and escape the lockdown. Every kilo you steal slows you down and makes you louder — greed is the real enemy. Features a recoverable detection meter, coin distractions, blinking laser tripwires, a secret loot, end-of-run ratings (GHOST, MASTERTHIEF, DEMOLITION) and a full labelled status panel with a live bank map.

## Run it

```sh
node main.ts
```

That copies the game to `/output` (or `$MAKEFUN_OUTPUT_DIR`) and writes the dossier. To play, serve the `game/` folder with any static file server and open `index.html` — it runs fully offline in a desktop browser, keyboard and mouse.
